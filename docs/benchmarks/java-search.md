# Java J2 搜索基准

- 日期：2026-08-12
- 机器：Apple Silicon M3，16GB 内存
- 运行时：Amazon Corretto 21.0.12，Spring Boot 3.5.16，sqlite-jdbc 3.53.2.1
- 数据集：固定生成2,000条 public 中文资料，其中200条命中“并发编程”
- 查询：`并发编程`，每页20条
- 过程：10次预热，50次测量；每次同时校验总数与分页条数

## 结果

| 指标 | 延迟 |
| --- | ---: |
| 中位数 | 1.325ms |
| p95 | 2.260ms |
| 回归门禁 | p95 < 1,000ms |

该门禁用于发现明显的算法或索引退化，不是线上服务 SLO。测试使用临时 SQLite 数据库，不读取真实个人知识。

从仓库根目录运行：

```sh
./scripts/java-test
```

基准由 `SqliteSearchBenchmarkTest` 执行；不同电脑上的绝对延迟会变化，固定数据量、命中数、预热次数和测量次数保持不变。
